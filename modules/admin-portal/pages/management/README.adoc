== Upgrading the Tools Suite

The self-managed version of the Admin Portal makes it easy to upgrade the any or all parts of the Tools Suite (GraphStudio, Admin Portal, Insights, and others).

Select btn:[Management > Upgrade TigerGraph Suite].
From there, you have the option of btn:[Manual Upgrade] or btn:[Online Check for Upgrade].

*Manual Upgrade* means you have downloaded a tools package from TigerGraph's download portal link:https://dl.tigergraph.com[].

*Online Check for Upgrade* will automatically search for the newest version of TigeGraph Tools that is compatible with your database version.

image:newer-tools-found.png[]

The user interface will guide you through the steps. Once the tool package has been unzipped and is ready, it will take 1 to 2 minutes to perform the upgrade.

[NOTE]
====
All users should exit the tools before performing the upgrade.
====
